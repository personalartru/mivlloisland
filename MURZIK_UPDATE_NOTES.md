# Мурзик и Чудо-остров — доработка

## Выполненные изменения

| Направление | Что изменено |
|---|---|
| Название | Пользовательские заголовки, локализация, страница публикации, маршрут и README переименованы с «Плюхик» на «Мурзик». Адрес репозитория и путь GitHub Pages `/plyuhik/` сохранены, чтобы не нарушать текущую публикацию. |
| Планшет | Добавлен постоянный крупный джойстик движения внизу слева, отдельная область камеры справа и увеличенные кнопки «Говорить» и «Прыжок» с учётом safe-area. На компактном альбомном экране элементы дополнительно уменьшаются, не перекрывая игровой HUD. |
| Озвучка | Добавлены 20 русских WAV-реплик для Бабушки Милы, Феи Росы, Боровичка и Кота Мурчика: начало задания, напоминание, сдача предметов, благодарность и фраза после завершения. Реплика запускается при открытии диалога; кнопку «Повторить» можно использовать для повторного прослушивания. Звук останавливается при паузе, закрытии диалога, выходе в меню или новом запуске. |

## Проверка

| Проверка | Итог |
|---|---|
| `pnpm typecheck` | Пройдена. |
| `pnpm test` | Пройдена: 81 тест. |
| `pnpm manus:build-source` | Пройдена. Статическая сборка содержит все 20 голосовых файлов в `dist/audio/dialogs/`. |
| `pnpm build` | В этой изолированной среде остановлена до сборки кода: исходные модели и SFX привязаны к неактивному управляемому хранилищу проекта. Ошибка не связана с внесёнными изменениями. |

## Публикация

Изменения подготовлены в локальной рабочей копии. Для публикации следует добавить изменённые файлы, включая `public/audio/dialogs/`, в коммит целевого репозитория и выполнить существующий процесс GitHub Pages в окружении, где восстановлены игровые модели и базовые SFX.

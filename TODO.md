# Мурзик и Чудо-остров — TODO

Одобренный Blueprint: детская 3D-игра-ходилка на Three.js. Забавный персонаж гуляет по фантастическому миру, выполняет простые задания и собирает различные предметы. Язык игры — русский, управление простое и понятное ребёнку, без насилия и проигрыша. Выбранные настройки: Fast-генерация 3D-моделей, риггинг и анимация персонажа — да, онлайн-таблица лидеров.

## [x] 1. Русская основа и оформление
- [x] Игра полностью на русском языке: все игровые строки, меню, HUD, диалоги, задания, результаты, загрузка.
- [x] Язык закреплён русский, переключатель языка и автоопределение по браузеру отключены.
- [x] Загрузочный экран — собственный: фон игры, название «Мурзик и Чудо-остров», реальный прогресс загрузки и Retry при ошибке; без наследуемого брендинга стартера.
- [x] Заголовок вкладки, иконка (favicon) и OG-обложка — собственные для игры; в `game-sharing.json` указаны название и описание игры.

## [x] 2. Мир Чудо-острова
- [x] Большой уютный остров в мультяшном фэнтези-стиле: центральная поляна, деревня гномов, пруд феи, грибной лес, холм с Деревом дружбы.
- [x] Дорожки, цветы, деревья, кусты, камни, заборчики, вода и декор создают цельный фантастический мир; камера от третьего лица.
- [x] Край острова безопасен: упасть за пределы нельзя или персонаж мягко возвращается на берег без штрафа и проигрыша.

## [x] 3. Забавный персонаж и управление
- [x] Мурзик — смешное пушистое существо с большой моделью, которая риггится и анимируется (idle + walk); визуал привязан к физическому корню, поворот по направлению движения, без «резинки» и скольжения.
- [x] Управление: WASD/стрелки — идти, мышь — камера, Space — прыжок, E — поговорить/взаимодействовать; на сенсорных экранах — джойстик, обзор, кнопки «Прыжок» и «Говорить».
- [x] Подсказки управления показываются ребёнку при первом запуске и учитывают способ ввода (клавиатура/геймпад/тач).
- [x] Нет таймера, жизней, врагов, урона и экрана поражения.

## [x] 4. Простые задания жителей
- [x] Четыре дружелюбных жителя с простыми и понятными заданиями: Бабушка Мила — 5 земляничек для пирога; Фея Роса — 4 волшебных кристалла для фонариков; Боровичок — 4 грибочка для корзинки; Кот Мурчик — 3 звёздочки.
- [x] Над жителем виден значок доступного задания; рядом с жителем появляется подсказка «E — поговорить» (на тач — кнопка «Говорить»).
- [x] Диалог с именем и репликой жителя, описанием задания и крупной кнопкой «Хорошо!». Если предметов ещё не хватает — житель просит собрать ещё и показывает, сколько осталось.
- [x] При достаточном количестве предметов задание завершается прямо в диалоге: благодарность, награда, отметка «Готово» и праздничный эффект. Задания можно выполнять в любом порядке.

- [x] HUD показывает активное задание, прогресс по предметам и общее число собранного; компас/стрелка указывает на ближайшую цель текущего задания.
- [x] После всех четырёх заданий — общий праздник: салют, финальный экран «Праздник на Чудо-острове!», звёзды, статистика и кнопки «Играть снова» / «На главную».

## [x] 6. 3D-модели (Fast mode) и анимации
- [x] Сгенерированы и интегрированы модели: Мурзик (T-поза для риггинга), Бабушка Мила, Фея Роса, Боровичок, Кот Мурчик, земляника, кристалл, грибочек, звёздочка, Дерево дружбы, домик бабушки.
- [x] Параметры Fast mode соблюдены: `model: "text/P1-20260311"`, `pbr: false`, `texture: true`, `texture_quality: "fast"`, `texture_version: "v3.5-20260815"`, `delight: true`, `purpose: "gamedev"`.
- [x] Мурзик заригжен (`rig/v1.0-20240301`, biped) и анимирован (idle + walk, in-place); анимации зациклены без рывков, корневое движение из клипов убрано, мировой перемещение — за игровым контроллером.
- [x] Модели зарегистрированы через sync/save, загружаются с CDN через `assets.lock.json`; при ошибке загрузки нужной модели показывается понятное сообщение и кнопка Retry, без подмены оплаченной модели процедурной.

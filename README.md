# Мурзик и Чудо-остров

Добрая детская 3D-игра-ходилка на Three.js. Мурзик гуляет по волшебному острову, а затем
отправляется на кристальную планету в глубине космоса: знакомится с жителями, выполняет простые
задания и собирает землянику, кристаллы, грибочки, звёздочки, звёздную пыль, туманные пузыри и
лунные цветы. В игре нет таймера, врагов, урона и поражения: закончить прогулку можно только
праздником.

```bash
pnpm install
pnpm dev      # локальная разработка
pnpm build    # typecheck + production build + бюджеты
pnpm test     # unit-тесты
pnpm smoke    # после build: браузерная прогулка и скриншоты в shots/
```

## Управление

- **Клавиатура:** WASD или стрелки — идти, мышь (зажать и вести) — осмотреться, Space — прыжок,
  E — поговорить, Esc — пауза.
- **Геймпад:** левый стик — идти, правый — камера, A — прыжок, X — поговорить, Start — пауза.
- **Планшет / сенсорный экран:** постоянный джойстик «Идти» внизу слева — ходьба; свайп по
  свободной правой части экрана — камера; крупные кнопки «Прыжок» и «Говорить» внизу справа.
  Управление учитывает безопасные отступы экрана и удобно работает в альбомной ориентации.

## Задания

Первый уровень — Чудо-остров: четыре задания и шестнадцать предметов.

| Житель | Что принести | Сколько |
| --- | --- | --- |
| Бабушка Мила | землянику для пирога | 5 |
| Фея Роса | волшебные кристаллы для фонариков | 4 |
| Боровичок | грибочки для корзинки | 4 |
| Кот Мурчик | звёздочки | 3 |

Второй уровень — Планета Звёздная: шесть заданий и двадцать четыре чуда.

| Космический друг | Что принести | Сколько |
| --- | --- | --- |
| Люмо, кристальный малыш | звёздную пыль для погасшего сердца | 5 |
| Кит Гром | туманные пузыри для звёздного фонтана | 3 |
| Тиара, хранительница колец | осколки разбитых колец планеты | 5 |
| Искра, комета | искорки из собственного хвоста | 4 |
| БИП-7, робот-садовник | кристальные семечки для замёрзшего сада | 4 |
| Лунатик | лунные цветы для сонного чая | 3 |

Задания можно выполнять в любом порядке. За каждый предмет даётся 100 очков дружбы, за
закрытое задание — 500, за общий праздник — 1000. Все фразы жителей острова озвучены на
русском, а каждый космический друг озвучивает своё первое приветствие; в диалоге доступна
кнопка «Повторить», а голос останавливается при закрытии окна или паузе.
Гостевая таблица лидеров сохраняет лучший результат; при недоступной сети игра продолжает
работать локально.
Гостевой ник виден другим игрокам; используйте игровой псевдоним, а не настоящее имя,
телефон или адрес.

## GitHub Pages

Публичная версия размещается по адресу `https://personalartru.github.io/murzik/`. Она использует
локальную доску почёта в браузере: результаты остаются на этом устройстве и не отправляются на
сервер. Для подготовки статического релиза выполните `pnpm build:github-pages` в рабочей копии,
где игровые модели и звуки восстановлены из управляемого хранилища; команда соберёт приложение,
включит медиафайлы в `dist/` и настроит пути для `/murzik/`. Для обновления Pages замените
содержимое корня ветки `gh-pages` файлами из `dist/` и отправьте ветку в GitHub.

После прохождения всех заданий на Чудо-острове открывается второй уровень — Планета Звёздная.
Доступ сохраняется в локальном прогрессе браузера. Уровень устроен как самостоятельный мир:
плоская кристальная планета с обрывом в открытый космос, кольцевой гигант и вторая луна на небе,
падающие звёзды, туманности, парящие островки и маяк, который загорается с каждым спасённым
другом. Вместо деревьев — кристальные шпили, вместо пруда — светящиеся кратеры, вместо избушки —
купол-обсерватория, вместо шляпы-дерева — маяк. Собственные жители, предметы, иконки HUD,
подсказки и финальный «Парад планет!»; на планете шесть заданий вместо четырёх. Управление
общее для обоих уровней, а прогресс, доска почёта и настройки — тоже.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/engine/` | фиксированный цикл, ввод, физика, рендер, звук, сохранения, загрузка ассетов |
| `src/game/config.ts` | активные параметры прогулки |
| `src/game/content.ts` | описания уровней: жители, предметы, задания, тексты-ключи |
| `src/game/layout.ts` | координаты жителей, предметов, воды, построек и маяка |
| `src/game/world.ts`, `world/planet.ts` | остров и кристальная планета, их декор и атмосфера |
| `src/game/world/shared.ts` | общие помощники: сид, текстуры земли, небо, свечения |
| `src/game/cosmic.ts`, `visuals.ts` | процедурные космические друзья и предметы, выбор визуала |
| `src/game/player.ts` | контроллер Мурзика и анимации idle/walk |
| `src/game/rules.ts` | чистые правила заданий и прогресса |
| `src/game/npcs.ts`, `items.ts` | жители, задания, сбор предметов |
| `src/game/game.ts` | сценарий прогулки, диалоги, праздник |
| `src/ui/`, `src/styles/main.css` | меню, HUD, диалоги, пауза, настройки, доска почёта |
| `src/i18n/ru.json` | все строки игры на русском |

## Ассеты

Модели сгенерированы для игры и зарегистрированы в `assets.lock.json`; production-сборка
читает их из управляемого хранилища. Исходные GLB лежат в `assets/models/`. Звуковые эффекты
взяты из Manus game asset catalog (CC0 / свободные для коммерческого использования) и лежат
в `assets/audio/`; production загружает их из управляемого хранилища, а dev — из локальных
исходников, без дублирования WAV в `dist/`. Озвучка диалогов находится в
`public/audio/dialogs/` и публикуется вместе с приложением. Шрифты Comfortaa и Nunito — OFL.
Библиотеки: three.js (MIT), Rapier (Apache-2.0).

## Примечания

- Все игровые строки — русские; переключателя языка и автоопределения нет.
- Модели загружаются с честным прогрессом; при сбое показывается сообщение и повтор загрузки,
  без подмены оплаченных моделей процедурными.
- `src/game/tuning.ts` — параметрический менеджер для Preview Tweak. Нестандартные игровые
  настройки помечают забег как `unranked`, чтобы не отправлять его в онлайн-таблицу.
